1.What is a computer network?
A computer network is a collection of interconnected computers and devices that communicate with each other to exchange data and share resources using communication protocols.

Examples of networked devices include:

Computers and laptops
Smartphones
Servers
Routers and switches
Printers
IoT devices
Why do we need computer networks?

Networks allow devices to:

Share data — files, messages, API requests, etc.
Share resources — printers, storage, internet connections
Communicate — email, video calls, messaging
Access remote services — web servers, databases, cloud applications
Build distributed systems — multiple machines cooperate to provide an application
How does a network work?

At a high level:

Sender
  ↓
Data
  ↓
Network protocols
  ↓
Switches / Routers
  ↓
Network
  ↓
Receiver

Devices use protocols such as TCP/IP to define how data is addressed, transmitted, routed, and received.

For example, when you open a website:

Your Computer
     ↓
   Router
     ↓
   Internet
     ↓
Web Server

Your computer sends requests to the server, and the server sends responses back.

Types of networks
Type	Typical scope	Example
PAN	Personal	Bluetooth devices
LAN	Local area	Home/office network
MAN	City/metropolitan area	City-wide network
WAN	Large geographic area	Internet
Important components
IP address → identifies a device/interface at the network layer.
MAC address → identifies a network interface at the data-link layer.
Switch → primarily connects devices within a LAN.
Router → forwards packets between different networks.
Protocol → defines communication rules, e.g., TCP, IP, HTTP, DNS.
Interview Takeaway

A computer network connects multiple devices so they can communicate and share data or resources. Communication is governed by networking protocols such as the TCP/IP protocol suite.
