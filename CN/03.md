3.Explain the TCP/IP model

The TCP/IP model is a networking model that describes how devices communicate over networks, including the Internet. It is based on the TCP/IP protocol suite and is more closely aligned with real-world Internet networking than the OSI reference model.

The commonly used TCP/IP model has 4 layers:

Layer	Main responsibility	Examples
4. Application	Provides network services to applications	HTTP, DNS, SMTP, SSH
3. Transport	End-to-end communication, reliability, flow/congestion control	TCP, UDP
2. Internet	Logical addressing and routing packets between networks	IP, ICMP
1. Network Access / Link	Local network delivery and transmission	Ethernet, Wi-Fi, ARP
1. Application Layer

This layer provides network functionality directly to applications.

Examples:

HTTP/HTTPS → web communication
DNS → domain-name resolution
SMTP → email transfer
SSH → remote access

For example, when a browser requests a webpage, the HTTP request originates at the application layer.

2. Transport Layer

The transport layer provides process-to-process communication between applications.

The two major protocols are:

TCP

Connection-oriented
Reliable, ordered delivery
Retransmits lost data
Provides flow and congestion control

UDP

Connectionless
No built-in guarantee of delivery or ordering
Lower protocol overhead
Useful when low latency is more important than guaranteed delivery

Example:

Browser process
      ↓
     TCP
      ↓
    Network
      ↓
TCP
      ↓
Web server process

Port numbers help identify the destination application/process.

3. Internet Layer

The Internet layer handles logical addressing and routing packets between networks.

The main protocol is IP (Internet Protocol).

Its responsibilities include:

IP addressing
Packet forwarding
Routing between networks

Routers primarily operate at this layer.

Example:

Computer A
   ↓
Router 1
   ↓
Router 2
   ↓
Server

IP determines how packets can travel between these different networks.

4. Network Access / Link Layer

This layer handles communication over the local network or physical network medium.

It deals with things such as:

Frames
MAC addresses
Local delivery
Ethernet
Wi-Fi

For example, your computer may use Wi-Fi to send a frame to your local router.

How data moves through the TCP/IP model

When you send an HTTP request:

Application
    ↓
HTTP data
    ↓
Transport
    ↓
TCP segment
    ↓
Internet
    ↓
IP packet
    ↓
Link
    ↓
Ethernet/Wi-Fi frame

At the receiving machine, the process happens in reverse:

Frame
  ↓
IP packet
  ↓
TCP segment
  ↓
HTTP data
  ↓
Application

This process is called encapsulation and decapsulation.

TCP/IP vs OSI
OSI	TCP/IP
7 layers	Commonly 4 layers
Reference model	Protocol suite + model
Application, Presentation, Session are separate	Combined into Application
Data Link + Physical are separate	Usually combined into Link/Network Access
Useful for conceptual understanding	Closely associated with real Internet protocols
Interview Takeaway

The TCP/IP model has four commonly used layers: Application, Transport, Internet, and Network Access/Link. It describes how application data is transformed into transport segments, IP packets, and link-layer frames as it travels across a network.
