4.OSI vs TCP/IP?

Both models describe how network communication is organized into layers, but they differ in structure and purpose.

Aspect	OSI Model	TCP/IP Model
Full form	Open Systems Interconnection	Transmission Control Protocol / Internet Protocol
Layers	7	Commonly 4
Purpose	Reference/conceptual model	Practical networking model/protocol suite
Application	Application, Presentation, Session	Application
Transport	Transport	Transport
Network	Network	Internet
Lower layers	Data Link + Physical	Network Access/Link
Real-world use	Mainly for understanding/design	Used extensively in Internet networking
Protocol dependency	Protocol-independent reference model	Closely associated with TCP/IP protocols
Layer mapping
OSI                         TCP/IP

Application ───────┐
Presentation ──────┼──→ Application
Session ───────────┘

Transport ───────────→ Transport

Network ─────────────→ Internet

Data Link ─────────┐
Physical ──────────┴──→ Network Access / Link
Key difference

The biggest structural difference is that OSI separates Application, Presentation, and Session, while TCP/IP generally combines them into the Application layer.

Similarly, OSI separates Data Link and Physical, while the common 4-layer TCP/IP model combines them into the Link/Network Access layer.

Interview takeaway:

OSI is a 7-layer reference model, while TCP/IP is a practical 4-layer model associated with the protocols used on the Internet. The TCP/IP model is not simply a renamed OSI model; their layers and purposes differ.
