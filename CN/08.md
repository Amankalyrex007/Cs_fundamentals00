8.TCP vs UDP?
Both TCP (Transmission Control Protocol) and UDP (User Datagram Protocol) are transport-layer protocols used to send data between applications over a network.

Key Differences
Feature	TCP	UDP
Connection	Connection-oriented	Connectionless
Reliability	Reliable	Best-effort
Ordering	Guarantees ordered delivery	No ordering guarantee
Retransmission	Yes	No built-in retransmission
Acknowledgments	Yes	No
Flow control	Yes	No TCP-style flow control
Congestion control	Yes	No TCP-style congestion control
Handshake	3-way handshake	No handshake
Data type	Byte stream	Independent datagrams
Overhead	Higher	Lower
Typical use	Web, file transfer, email	DNS, streaming, gaming, real-time communication
How TCP works

TCP establishes a connection using the three-way handshake:

Client → SYN
Server → SYN + ACK
Client → ACK

It then uses sequence numbers, acknowledgments, retransmissions, flow control, and congestion control to provide reliable, ordered delivery.

If a packet is lost:

Packet 1 → received
Packet 2 → received
Packet 3 → lost
Packet 4 → received

TCP detects the loss and retransmits packet 3.
How UDP works

UDP simply sends datagrams without establishing a connection:

Sender → Packet 1
Sender → Packet 2
Sender → Packet 3
Sender → Packet 4

If packet 3 is lost, UDP itself does not retransmit it. If reliability is required, the application or a higher-level protocol must implement it.

When to use which?

Use TCP when:

Data must arrive reliably and in order.
Losing data is unacceptable.
Examples: HTTP/1.1, HTTP/2, file transfer, database connections.

Use UDP when:

Low overhead and timely delivery are important.
Some packet loss is acceptable or handled by the application.
Examples: DNS, real-time audio/video, online gaming.

Important interview point: Don't say “UDP is always faster than TCP.” UDP has less protocol overhead, but actual performance depends on the application, network conditions, and what reliability mechanisms the application needs.

One-line interview answer

TCP provides reliable, ordered, connection-oriented byte-stream communication, while UDP provides lightweight, connectionless datagram communication without built-in delivery or ordering guarantees.
