32.What is a table, row, column, and record?
Answer

These are fundamental concepts in a relational database.

Consider a Students table:

student_id	name	course	marks
101	Rahul	B.Tech	85
102	Priya	BCA	91
103	Amit	B.Tech	78
1. What is a Table?

A table is a structured collection of related data organized into rows and columns.

For example:

Students

is a table containing information about students.

Think of a table like a spreadsheet where each table represents one type of entity or relationship.

2. What is a Column?

A column represents a particular attribute/property of the data.

In our example:

student_id
name
course
marks

are columns.

Each column generally has a defined data type.

For example:

student_id → INTEGER
name       → VARCHAR
marks      → INTEGER

So the marks column represents the marks of students.

3. What is a Row?

A row represents one complete set of values in a table.

For example:

101 | Rahul | B.Tech | 85

is one row.

It represents one student's information.

Another row:

102 | Priya | BCA | 91

represents another student.

4. What is a Record?

In a relational database, record is commonly used as another term for a row.

For example:

101 | Rahul | B.Tech | 85

is one record in the Students table.

So:

Table
 ├── Row / Record
 ├── Row / Record
 └── Row / Record
Quick comparison
Term	Meaning	Example
Table	Collection of related data	Students
Column	Attribute/property	name, marks
Row	One set of related values	101, Rahul, B.Tech, 85
Record	Usually another term for a row	Rahul's complete data
Easy way to remember

Think of a student registration form:

Table → entire collection of student forms
Column → a field on the form, such as Name or Course
Row → one student's completed form
Record → the data representing that student
Interview takeaway

A table stores related data, columns define the attributes, and rows contain individual records. In relational databases, “row” and “record” are generally used interchangeably.

Common mistake: Don't say that a column represents an individual student. A column represents an attribute, while a row/record represents an individual entity or relationship instance.
