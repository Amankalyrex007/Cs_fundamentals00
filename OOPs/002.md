2.What are the four pillars of OOP?
Answer

The four pillars of Object-Oriented Programming (OOP) are:

Encapsulation
Abstraction
Inheritance
Polymorphism

The provided repository guide emphasizes consistent terminology and specifically lists these OOP concepts among the concepts that should be distinguished, but it does not itself provide detailed definitions.

1. Encapsulation

Encapsulation means bundling data and the methods that operate on that data together, while controlling how the internal data is accessed.

class BankAccount:
    def __init__(self):
        self.__balance = 0

    def deposit(self, amount):
        self.__balance += amount

    def get_balance(self):
        return self.__balance

Here, __balance is kept internal to the class, and access is provided through methods.

Why? It helps protect an object's internal state and prevents uncontrolled modification.

2. Abstraction

Abstraction means exposing the essential functionality while hiding unnecessary implementation details.

For example, when you call:

car.start()

you don't need to know every internal operation involved in starting the engine.

Why? It reduces complexity for the user of the object.

3. Inheritance

Inheritance allows one class to derive properties and behaviors from another class.

class Animal:
    def speak(self):
        print("Animal speaks")


class Dog(Animal):
    pass


dog = Dog()
dog.speak()

Dog inherits the speak() method from Animal.

Why? It can support code reuse and represent relationships between related classes.

4. Polymorphism

Polymorphism means that the same interface or method call can produce different behavior depending on the object involved.

class Dog:
    def speak(self):
        print("Bark")


class Cat:
    def speak(self):
        print("Meow")


for animal in [Dog(), Cat()]:
    animal.speak()

The same call:

animal.speak()

produces different behavior for Dog and Cat.

Why? It allows code to work with different object types through a common interface.

Quick Revision
Pillar	Core idea
Encapsulation	Bundle and protect data + methods
Abstraction	Hide unnecessary implementation details
Inheritance	Derive/reuse behavior from another class
Polymorphism	Same interface, different behavior
Interview Takeaway

A concise interview answer is:

The four pillars of OOP are encapsulation, abstraction, inheritance, and polymorphism. Encapsulation protects and organizes data, abstraction hides unnecessary complexity, inheritance enables deriving classes from existing classes, and polymorphism allows the same interface to behave differently for different objects.
