3.What is a class and what is an object?
Answer

A class is a blueprint or template that defines the data (attributes) and behavior (methods) that objects of that type will have.

An object is a specific instance of a class. It has its own state (actual values for the attributes) and can use the behavior defined by the class.

A simple way to remember it:

Class = blueprint
Object = actual thing created from the blueprint

Example

Consider a Student class:

class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        print(f"My name is {self.name}")

We can create objects from this class:

student1 = Student("Aman", 20)
student2 = Student("Rahul", 21)

student1.introduce()
student2.introduce()

Here:

Student → class
student1 → object
student2 → object
name and age → attributes/state
introduce() → method/behavior

Although student1 and student2 are created from the same class, they have different states:

student1
    name = "Aman"
    age  = 20

student2
    name = "Rahul"
    age  = 21

The class defines what a Student object looks like and can do; each object contains its own actual data.

Class vs Object
Aspect	Class	Object
Meaning	Blueprint/template	Instance of a class
Defines	Attributes and methods	Actual state and behavior
Memory	Defining a class doesn't represent one particular entity	Object occupies memory when instantiated
Example	Student	student1
Number	One class can create many objects	Each object is a separate instance
Real-World Analogy

Think about a house blueprint.

The blueprint specifies:

number of rooms
doors
windows
structure

But the blueprint itself isn't a particular house.

Using that blueprint, we can construct multiple houses:

Blueprint → Class

House 1 → Object
House 2 → Object
House 3 → Object

Each house follows the same general design but can have different properties, such as wall color or furniture.

Why is this distinction important?

Classes allow us to define a concept once and then create many objects from it.

For example, an e-commerce application could have:

class Product:
    ...

Then thousands of product objects can be created from that class:

Product class
      ↓
 ┌────┼────┐
 ↓    ↓    ↓
P1   P2   P3

This supports reusability, organization, and modularity in larger programs.

Common Mistake

A class and an object are not the same thing.

A class describes what an object should contain and do. An object is a concrete instance created from that class.

Also, the exact implementation details of classes and objects can vary between programming languages, so concepts such as memory allocation should be explained in the context of the particular language.

Interview Takeaway

A class is a blueprint that defines attributes and methods, while an object is a concrete instance of that class. One class can be used to create many objects, and each object can have its own state.
