6.What is inheritance?
Answer

Inheritance is an OOP mechanism in which a new class (child/subclass) derives properties and behaviors from an existing class (parent/superclass).

The main idea is:

Create a new class by reusing and extending the functionality of an existing class.

This is useful when multiple classes have some common characteristics or behavior.

Simple Example
class Animal:
    def eat(self):
        print("Animal is eating")


class Dog(Animal):
    def bark(self):
        print("Dog is barking")


dog = Dog()

dog.eat()   # inherited from Animal
dog.bark() # defined in Dog

Here:

Animal → parent/base class
Dog → child/derived class
eat() → inherited by Dog
bark() → specifically defined by Dog

So the Dog class can reuse functionality from Animal without redefining eat().

Why is inheritance used?

The primary reasons are:

Code reuse
Common functionality can be implemented once in a parent class.
Extensibility
A child class can add new attributes or methods.
Hierarchical modeling
It can represent an "is-a" relationship.

For example:

Animal
 ├── Dog
 ├── Cat
 └── Bird

A dog is an animal, so inheritance can be a natural model.

Method Overriding

A child class can also provide its own implementation of an inherited method. This is called method overriding.

class Animal:
    def speak(self):
        print("Some sound")


class Dog(Animal):
    def speak(self):
        print("Bark")


class Cat(Animal):
    def speak(self):
        print("Meow")

Now:

Dog().speak()  # Bark
Cat().speak()  # Meow

The subclasses inherit the general structure of Animal but provide their own behavior for speak().

This is closely related to polymorphism, which is another pillar of OOP.

Types of Inheritance

Common forms include:

Type	Meaning
Single inheritance	One child inherits from one parent
Multilevel inheritance	A class inherits from a class that itself inherits from another class
Hierarchical inheritance	Multiple child classes inherit from the same parent
Multiple inheritance	One child class inherits from multiple parent classes
Hybrid inheritance	Combination of multiple inheritance patterns

The availability and implementation of these forms depend on the programming language.

For example, Python supports multiple inheritance:

class A:
    pass


class B:
    pass


class C(A, B):
    pass
Inheritance vs Composition

Inheritance should not automatically be used whenever code needs reuse.

Consider:

Car → Engine

A car has an engine, rather than being an engine.

This is generally modeled using composition:

class Engine:
    def start(self):
        print("Engine started")


class Car:
    def __init__(self):
        self.engine = Engine()

So a useful rule is:

"is-a" → potentially inheritance
"has-a" → potentially composition

The actual design should depend on the relationship and how the components are expected to evolve.

Common Mistakes

1. Thinking inheritance is only about code reuse

Inheritance can provide reuse, but it also establishes a relationship between types and affects substitutability and design.

2. Using inheritance everywhere

Deep or inappropriate inheritance hierarchies can make software difficult to understand and modify. Composition is often an alternative.

3. Confusing inheritance with polymorphism

Inheritance describes a relationship between classes. Polymorphism allows objects of different types to be used through a common interface.

Interview Takeaway

Inheritance allows a child class to derive and reuse attributes and methods from a parent class. The child can also extend or override that behavior. It is useful for representing appropriate "is-a" relationships, but should be used carefully because composition can sometimes provide a more flexible design.
