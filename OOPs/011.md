11.What are constructors?
Answer

A constructor is a special method that is automatically called when an object of a class is created. Its main purpose is to initialize the object's attributes and set its initial state.

In simple terms:

Class defines what an object should have, and the constructor initializes those values when the object is created.

Example in Python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

student1 = Student("Rahul", 21)

print(student1.name)  # Rahul
print(student1.age)   # 21

Here:

Student → class
student1 → object
__init__() → constructor-like initialization method
name and age → object attributes
"Rahul" and 21 → initial values

When we write:

student1 = Student("Rahul", 21)

Python automatically calls:

__init__("Rahul", 21)

to initialize the object.

Why are constructors used?

Constructors are mainly used to:

Initialize object attributes
Set the initial state of an object
Perform required setup when an object is created
Ensure an object starts in a valid state

For example, in an ML project, a model class might initialize configuration values:

class Model:
    def __init__(self, learning_rate, epochs):
        self.learning_rate = learning_rate
        self.epochs = epochs

model = Model(0.01, 100)

The constructor ensures every Model object gets its required configuration.

Types of constructors

Depending on the programming language, constructors can be categorized differently. Commonly discussed types include:

Default constructor — takes no arguments other than the implicit object reference.
Parameterized constructor — accepts arguments to initialize the object.
Copy constructor — creates an object using another object's values; common in C++, but not a special built-in constructor type in Python.

Python does not have traditional constructor overloading like Java or C++. Instead, default values or *args/**kwargs can be used to support different initialization patterns.

Constructor vs normal method
Constructor	Normal method
Used primarily to initialize an object	Performs some operation
Called automatically during object creation	Usually called explicitly
Python uses __init__() for initialization	Can have any valid method name
Establishes initial object state	Changes or uses object state
Important Python point

Technically, __init__() is an initializer, not the method that actually creates the object. Object creation is handled by __new__(), while __init__() initializes the newly created object.

For most interviews, however, it is acceptable to say:

"__init__() is Python's constructor-like method used to initialize an object."

Interview takeaway

Constructor = automatic initialization of an object's state when the object is created.
