12.What is a destructor?
Answer

A destructor is a special method that is called when an object is being destroyed or garbage-collected. Its purpose is generally to perform cleanup operations, such as releasing resources held by the object.

In simple terms:

Constructor initializes an object; destructor performs cleanup when the object is no longer needed.

Example in Python

Python provides a destructor-like method called __del__():

class Student:
    def __init__(self, name):
        self.name = name
        print("Object created")

    def __del__(self):
        print("Object destroyed")


student = Student("Rahul")
del student

Output:

Object created
Object destroyed

Here:

__init__() initializes the object.
__del__() is called when Python is destroying the object.
del student removes the reference to the object. If that was the last reference, the object can become eligible for destruction.
Why are destructors used?

They can be used for cleanup such as:

Closing resources
Releasing memory or other resources
Closing files
Cleaning up temporary objects
Logging when an object is being destroyed

However, __del__() should not generally be relied upon for critical resource cleanup in Python, because its execution timing is not guaranteed in the same way as deterministic cleanup mechanisms.

For example, for files, prefer:

with open("data.txt", "r") as file:
    data = file.read()

The with statement provides predictable resource cleanup.

Constructor vs Destructor
Constructor	Destructor
Initializes an object	Performs cleanup when an object is being destroyed
Python commonly uses __init__()	Python provides __del__()
Called during object initialization	Called when the object is finalized
Sets the initial state	Can clean up resources
Happens near object creation	Timing of execution can depend on object lifetime/garbage collection
Important interview point

Do not say:

"del obj directly calls the destructor."

More accurately, del obj removes a reference. If no references remain, the object may become eligible for destruction, and __del__() may then be invoked.

Interview takeaway

A destructor is a special method associated with object destruction and cleanup. In Python, __del__() is a destructor-like method, but deterministic resource cleanup should generally use mechanisms such as with/context managers rather than relying on __del__().
