# Q14. Composition vs Inheritance?

Composition and inheritance are two ways of establishing relationships between classes.

* **Inheritance** → `is-a` relationship
* **Composition** → `has-a` relationship

## 1. Inheritance — "Is-a"

Inheritance means a child class derives from a parent class and reuses its properties and methods.

### Example

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def eat(self):
        print(f"{self.name} is eating")


class Dog(Animal):
    def bark(self):
        print(f"{self.name} is barking")


dog = Dog("Buddy")

dog.eat()
dog.bark()
```

Output:

```text
Buddy is eating
Buddy is barking
```

Here:

```text
Dog IS-A Animal
```

`Dog` inherits the `name` attribute and `eat()` method from `Animal`.

---

## 2. Composition — "Has-a"

Composition means a class contains an object of another class and uses its functionality.

### Example

```python
class Engine:
    def __init__(self, engine_type):
        self.engine_type = engine_type

    def start(self):
        print(f"{self.engine_type} engine started")


class Car:
    def __init__(self, brand, engine):
        self.brand = brand
        self.engine = engine

    def start_car(self):
        print(f"{self.brand} is starting...")
        self.engine.start()


engine = Engine("Electric")
car = Car("Tesla", engine)

car.start_car()
```

Output:

```text
Tesla is starting...
Electric engine started
```

Here:

```text
Car HAS-A Engine
```

The `Car` object contains an `Engine` object and delegates the engine-related work to it.

---

## 3. Inheritance vs Composition

| Feature      | Inheritance          | Composition               |
| ------------ | -------------------- | ------------------------- |
| Relationship | Is-a                 | Has-a                     |
| Reuse        | Through parent class | Through contained objects |
| Coupling     | Usually tighter      | Usually looser            |
| Flexibility  | Can be less flexible | Usually more flexible     |
| Main idea    | Extend a class       | Combine objects           |
| Example      | Dog → Animal         | Car → Engine              |

---

## 4. Composition with Polymorphism

One advantage of composition is that we can replace a component without changing the main class.

### Example

```python
class PetrolEngine:
    def start(self):
        print("Petrol engine started")


class ElectricEngine:
    def start(self):
        print("Electric engine started")


class Car:
    def __init__(self, engine):
        self.engine = engine

    def start(self):
        self.engine.start()


petrol_car = Car(PetrolEngine())
electric_car = Car(ElectricEngine())

petrol_car.start()
electric_car.start()
```

Output:

```text
Petrol engine started
Electric engine started
```

The `Car` does not need to know which type of engine it has. It simply calls `start()`.

This is **composition + polymorphism**.

---

## 5. When to Use Inheritance?

Use inheritance when there is a genuine **is-a** relationship.

### Example

```text
Vehicle
 ├── Car
 └── Bike
```

A `Car` is a `Vehicle`, and a `Bike` is a `Vehicle`.

```python
class Vehicle:
    def move(self):
        print("Vehicle is moving")


class Car(Vehicle):
    def drive(self):
        print("Car is driving")


car = Car()

car.move()
car.drive()
```

---

## 6. When to Use Composition?

Use composition when one object **contains or uses** another object.

### Examples

```text
Car → Engine
Computer → CPU
House → Room
MLPipeline → Model
```

For example:

```python
class CPU:
    def process(self):
        print("CPU is processing")


class Computer:
    def __init__(self):
        self.cpu = CPU()

    def run(self):
        self.cpu.process()
        print("Computer is running")


computer = Computer()
computer.run()
```

Here:

```text
Computer HAS-A CPU
```

---

## 7. Main Difference

```text
Inheritance

Dog
 ↓
Animal

Dog IS-A Animal
```

```text
Composition

Car
 ↓
Engine

Car HAS-A Engine
```

### Simple Rule

> **Use inheritance for "is-a" relationships and composition for "has-a" relationships.**
