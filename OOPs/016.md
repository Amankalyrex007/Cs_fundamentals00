# Q16. What Are Access Modifiers?

Access modifiers are keywords used in OOP to control the **visibility and accessibility** of classes, methods, variables, and other members.

In simple terms:

> **Access modifiers determine who can access a particular member of a class.**

They are important for **encapsulation, data protection, and controlling how other parts of a program interact with an object.**

---

## Common Access Modifiers

The exact modifiers depend on the programming language.

In languages such as Java and C++, the commonly discussed access modifiers are:

| Modifier                    | Accessibility                                   | Purpose                                              |
| --------------------------- | ----------------------------------------------- | ---------------------------------------------------- |
| `public`                    | Accessible from anywhere                        | Expose functionality openly                          |
| `private`                   | Accessible only within the class                | Hide internal implementation/data                    |
| `protected`                 | Accessible within the class and derived classes | Support inheritance while restricting general access |
| `default` / package-private | Same package in Java                            | Restrict access to a package                         |

---

## 1. Public

A `public` member can generally be accessed from outside the class.

### Example

```java
class Student {
    public String name = "Rahul";
}

class Main {
    public static void main(String[] args) {
        Student student = new Student();

        System.out.println(student.name);
    }
}
```

Output:

```text
Rahul
```

Here, `name` is publicly accessible.

```text
Student
   |
   └── public name
          ↓
   Accessible from outside
```

---

## 2. Private

A `private` member can only be accessed directly within its defining class.

### Example

```java
class BankAccount {
    private double balance;

    public void deposit(double amount) {
        balance += amount;
    }

    public double getBalance() {
        return balance;
    }
}

class Main {
    public static void main(String[] args) {
        BankAccount account = new BankAccount();

        account.deposit(1000);

        System.out.println(account.getBalance());
    }
}
```

Output:

```text
1000.0
```

External code cannot directly modify `balance`:

```java
account.balance = -1000;   // Not allowed
```

Instead, controlled methods such as `deposit()` can manage access.

This supports **encapsulation**.

---

## 3. Protected

A `protected` member is generally accessible within the defining class and by subclasses.

### Example

```java
class Animal {
    protected String name = "Animal";
}

class Dog extends Animal {

    void showName() {
        System.out.println(name);
    }
}

class Main {
    public static void main(String[] args) {
        Dog dog = new Dog();

        dog.showName();
    }
}
```

Output:

```text
Animal
```

Here, `Dog` can access the inherited `protected` member.

```text
Animal
   |
   └── protected name
          ↑
         Dog
```

## Access Modifiers in Python

Python does not enforce access modifiers in exactly the same way as Java or C++.

Instead, Python uses **naming conventions**:

```python
class Student:
    def __init__(self):
        self.name = "Rahul"          # public
        self._age = 21               # protected by convention
        self.__password = "1234"     # private-like
```

The naming conventions are:

```text
name
↓
Public
```

```text
_age
↓
Protected by convention
```

```text
__password
↓
Private-like
```

### Example

```python
class Student:
    def __init__(self):
        self.name = "Rahul"
        self._age = 21
        self.__password = "1234"

    def show_details(self):
        print(self.name)
        print(self._age)
        print(self.__password)


student = Student()

print(student.name)
print(student._age)

student.show_details()
```

Output:

```text
Rahul
21
Rahul
21
1234
```

Python's `__password` is not truly private in the same strict sense as Java's `private`; Python uses **name mangling** rather than strict access enforcement.

## Why Are Access Modifiers Important?

They help:

* Protect internal data
* Implement encapsulation
* Control how objects are used
* Reduce accidental modification
* Hide implementation details
* Make code easier to maintain

For example, instead of allowing:

```text
account.balance = -50000
```

we can expose controlled methods:

```text
account.deposit(1000)
account.withdraw(500)
```

### Example

```java
class BankAccount {
    private double balance;

    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    public void withdraw(double amount) {
        if (amount > 0 && amount <= balance) {
            balance -= amount;
        }
    }
}
```

The class can then validate whether the operation is valid.

For example:

```text
deposit(1000)  → Allowed
withdraw(500)  → Allowed
withdraw(5000) → Rejected
```

---

## Interview Takeaway

Access modifiers control the visibility and accessibility of class members.

Common modifiers include:

```text
public
private
protected
default
```

They are an important part of **encapsulation** because they control how other parts of a program interact with an object's internal state.
