# Q17. What is `this` / `self`?

`this` and `self` are references to the **current object (instance)** of a class.

They allow an object to access its own attributes and methods.

* `self` → commonly used in Python
* `this` → commonly used in Java, C++, C#, and other languages

In simple terms:

> **`self` / `this` means "the current object."**

---

## Example in Python

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        print(f"My name is {self.name} and I am {self.age} years old.")


student1 = Student("Rahul", 21)

student1.introduce()
```

Output:

```text
My name is Rahul and I am 21 years old.
```

Here:

```text
self.name
self.age
```

refer to the attributes belonging to the current `Student` object.

When we execute:

```python
student1.introduce()
```

`self` refers to `student1`.

---

## Why Is `self` Needed?

Consider:

```python
class Student:
    def __init__(self, name):
        self.name = name
```

There are two different things here:

```text
name
    ↓
Parameter / local variable

self.name
    ↓
Attribute belonging to the object
```

So:

```python
self.name = name
```

means:

> Take the value provided through `name` and store it in the current object's `name` attribute.

### Small Example

```python
student1 = Student("Rahul")
student2 = Student("Aman")

print(student1.name)
print(student2.name)
```

Output:

```text
Rahul
Aman
```

Conceptually:

```text
student1.name → "Rahul"
student2.name → "Aman"
```

The same class can therefore use `self` to refer to different objects.

---

## `this` in Java

The equivalent concept in Java is `this`.

```java
class Student {
    String name;

    Student(String name) {
        this.name = name;
    }

    void introduce() {
        System.out.println("My name is " + this.name);
    }
}
```

Here:

```java
this.name
```

refers to the `name` belonging to the current object.

### Small Example

```java
Student student1 = new Student("Rahul");
Student student2 = new Student("Aman");

student1.introduce();
student2.introduce();
```

Output:

```text
My name is Rahul
My name is Aman
```

`this` refers to the object on which the method is called.

---

## Important Python Point

In Python, `self` is **not a reserved keyword**.

It is the conventional name for the first parameter of an instance method.

For example, this technically works:

```python
class Student:
    def introduce(current_object):
        print(current_object)
```

But using `self` is the standard and strongly recommended convention:

```python
class Student:
    def introduce(self):
        print(self)
```

### Example

```python
student = Student()
student.introduce()
```

Here, Python passes the current object to the first parameter automatically.

---

## `self` vs `this`

| Feature            | `self`                                 | `this`                             |
| ------------------ | -------------------------------------- | ---------------------------------- |
| Common languages   | Python                                 | Java, C++, C#                      |
| Refers to          | Current object                         | Current object                     |
| Typical use        | Access instance attributes/methods     | Access instance attributes/methods |
| Python requirement | Explicitly written as method parameter | Not applicable                     |

---

## Simple Example to Remember

### Python

```python
class Car:
    def __init__(self, brand):
        self.brand = brand

    def show(self):
        print(self.brand)


car = Car("Toyota")
car.show()
```

Here:

```text
self → car
self.brand → car.brand
```

### Java

```java
class Car {
    String brand;

    Car(String brand) {
        this.brand = brand;
    }

    void show() {
        System.out.println(this.brand);
    }
}
```

Here:

```text
this → current Car object
this.brand → current object's brand
```

---

## Interview Takeaway

`self` in Python and `this` in languages such as Java/C++ refer to the **current object**.

They are used to access the object's instance variables and methods and to distinguish instance attributes from local variables or parameters.
