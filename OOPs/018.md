18.What issuper?
Answer

super is used in inheritance to access members of a parent (superclass) from a child (subclass).

In simple terms:

super allows a child class to use the parent class's methods or constructor without directly referring to the parent class by name.

It is especially useful when a child class overrides a method but still wants to use the parent's implementation.

Example in Python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print("Animal makes a sound")


class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed

    def speak(self):
        super().speak()
        print("Dog barks")


dog = Dog("Bruno", "Labrador")
dog.speak()

Output:

Animal makes a sound
Dog barks
What is happening?

When we create:

dog = Dog("Bruno", "Labrador")

the child constructor runs:

def __init__(self, name, breed):

Inside it:

super().__init__(name)

calls the parent class's __init__():

Animal.__init__(self, name)

This initializes:

self.name = name

Then the child initializes its own attribute:

self.breed = breed
super() with method overriding

Suppose a child overrides a parent method:

class Animal:
    def speak(self):
        print("Animal sound")


class Dog(Animal):
    def speak(self):
        super().speak()
        print("Dog bark")

Calling:

dog = Dog()
dog.speak()

produces:

Animal sound
Dog bark

So super().speak() allows the child to reuse the parent's implementation before adding its own behavior.

Why use super()?

It helps with:

Calling the parent constructor
Reusing parent methods
Avoiding hard-coded parent class names
Supporting inheritance hierarchies more cleanly
Working correctly with Python's Method Resolution Order (MRO), especially in multiple inheritance
super() vs directly calling the parent

You could sometimes write:

Animal.__init__(self, name)

instead of:

super().__init__(name)

But super() is generally preferred because it works with Python's MRO and makes cooperative multiple inheritance possible.

Important interview point

super() does not simply mean "call my immediate parent."

More precisely, it provides a proxy that follows Python's Method Resolution Order (MRO) to find the next appropriate implementation.

This becomes particularly important in multiple inheritance.

Interview takeaway

super() is used in a subclass to access the next implementation in the inheritance hierarchy, commonly to call a parent class's constructor or an overridden method. In Python, it follows the class's Method Resolution Order (MRO), making it important for clean and cooperative inheritance
