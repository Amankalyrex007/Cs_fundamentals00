# Q18. What Is `super`?

`super` is used in inheritance to access members of a parent (superclass) from a child (subclass).

In simple terms:

> **`super` allows a child class to use the parent class's methods or constructor without directly referring to the parent class by name.**

It is especially useful when a child class overrides a method but still wants to use the parent's implementation.

---

## Example in Python

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(f"{self.name} makes a sound")


class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed

    def show_details(self):
        print(f"Name: {self.name}")
        print(f"Breed: {self.breed}")


dog = Dog("Bruno", "Labrador")
dog.show_details()
```

Output:

```text
Name: Bruno
Breed: Labrador
```

Here:

```python
super().__init__(name)
```

calls the constructor of `Animal`.

---

## What Is Happening?

When we create:

```python
dog = Dog("Bruno", "Labrador")
```

the child constructor runs:

```python
def __init__(self, name, breed):
```

Inside it:

```python
super().__init__(name)
```

calls the parent class's `__init__()`:

```python
Animal.__init__(self, name)
```

This initializes:

```python
self.name = name
```

Then the child initializes its own attribute:

```python
self.breed = breed
```

So the object contains:

```text
name  → "Bruno"
breed → "Labrador"
```

### Small Flow

```text
Dog object
    |
    ├── name  → Bruno
    └── breed → Labrador
```

---

## `super()` With Method Overriding

Suppose a child overrides a parent method:

```python
class Animal:
    def speak(self):
        print("Animal makes a sound")


class Dog(Animal):
    def speak(self):
        super().speak()
        print("Dog barks")


dog = Dog()
dog.speak()
```

Output:

```text
Animal makes a sound
Dog barks
```

Here:

```python
super().speak()
```

calls the parent's `speak()` method.

Then:

```python
print("Dog barks")
```

adds the child's own behavior.

So:

```text
Parent behavior
      ↓
super().speak()
      ↓
Child behavior
```

---

## Why Use `super()`?

It helps with:

* Calling the parent constructor
* Reusing parent methods
* Avoiding hard-coded parent class names
* Supporting inheritance hierarchies more cleanly
* Working correctly with Python's Method Resolution Order (MRO), especially in multiple inheritance

### Example

```python
class Person:
    def __init__(self, name):
        self.name = name


class Student(Person):
    def __init__(self, name, course):
        super().__init__(name)
        self.course = course


student = Student("Rahul", "Python")

print(student.name)
print(student.course)
```

Output:

```text
Rahul
Python
```

The `Student` class reuses the initialization logic of `Person`.

---

## `super()` vs Directly Calling the Parent

You could sometimes write:

```python
Animal.__init__(self, name)
```

instead of:

```python
super().__init__(name)
```

For example:

```python
class Animal:
    def __init__(self, name):
        self.name = name


class Dog(Animal):
    def __init__(self, name):
        super().__init__(name)
```

Using `super()` is generally preferred because it works with Python's **Method Resolution Order (MRO)** and supports cooperative multiple inheritance.

---

## Important Interview Point

`super()` does not simply mean **"call my immediate parent."**

More precisely, it provides a proxy that follows Python's **Method Resolution Order (MRO)** to find the next appropriate implementation.

This becomes particularly important in multiple inheritance.

### Simple Example

```python
class A:
    def show(self):
        print("A")


class B(A):
    def show(self):
        super().show()
        print("B")


class C(B):
    def show(self):
        super().show()
        print("C")


obj = C()
obj.show()
```

Output:

```text
A
B
C
```

The calls follow the MRO:

```text
C → B → A
```

---

## Interview Takeaway

`super()` is used in a subclass to access the next implementation in the inheritance hierarchy, commonly to call a parent class's constructor or an overridden method.

In Python, it follows the class's **Method Resolution Order (MRO)**, making it important for clean and cooperative inheritance.
