19.What are members?
Answer

Static members are members of a class that belong to the class itself rather than to individual objects (instances).

They are typically shared by all objects of that class.

Instance member → belongs to each object
Static member → belongs to the class

Static members can include static variables (class variables) and static methods.

1. Static variable

A static variable is shared among all instances of a class.

For example, in Python:

class Student:
    school = "ABC School"   # class/static variable

    def __init__(self, name):
        self.name = name     # instance variable


s1 = Student("Rahul")
s2 = Student("Aman")

print(s1.school)
print(s2.school)

Both objects access the same class-level value:

ABC School
ABC School

Conceptually:

Student class
     |
     └── school = "ABC School"
          ↑          ↑
         s1         s2

If school represents information common to all students, keeping one shared value is more appropriate than storing a separate copy for every object.

2. Static method

A static method belongs to the class and does not require an instance (self) to operate.

In Python, it can be created using @staticmethod:

class MathUtils:

    @staticmethod
    def add(a, b):
        return a + b


result = MathUtils.add(10, 20)
print(result)

Output:

30

Notice that we don't need:

obj = MathUtils()

to call add().

A static method is useful when a function is logically related to a class but doesn't need object-specific data.

Static vs instance members
Feature	Static/Class Member	Instance Member
Belongs to	Class	Individual object
Copies	Generally shared	Each object has its own
Access	Can often be accessed through class	Usually through object
Python example	Class variable / @staticmethod	self.name
Needs object state?	Not necessarily	Usually yes
Example
class Employee:
    company = "TechCorp"       # class/static member

    def __init__(self, name):
        self.name = name        # instance member

    @staticmethod
    def company_policy():
        return "Work from office 3 days a week"

Here:

company → class-level data shared by employees
name → individual employee data
company_policy() → static method; it doesn't need self

Usage:

print(Employee.company)
print(Employee.company_policy())

employee = Employee("Rahul")
print(employee.name)
Important language difference

The exact meaning and syntax of static members varies by language.

For example, Java explicitly uses the static keyword:

class Employee {
    static String company = "TechCorp";

    static void showCompany() {
        System.out.println(company);
    }
}

Python generally uses the terms class variable and static method rather than declaring a variable with a static keyword.

When should static members be used?

They are useful when the data or behavior is common to the class rather than specific to an individual object.

Examples include:

Counters shared across instances
Configuration/constants
Utility functions
Factory/helper methods
Information common to all objects
Common mistake

A static member should not be used simply because it is convenient. If a value belongs to an individual object, it should normally be an instance member.

For example:

Employee.company  → shared
employee.salary   → individual
employee.name     → individual
Interview takeaway

Static members belong to the class rather than individual objects. Static variables can hold class-level shared data, while static methods provide behavior that doesn't depend on a particular object's state.
