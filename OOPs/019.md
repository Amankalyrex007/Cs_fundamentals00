# Q19. What Are Members?

**Static members** are members of a class that belong to the **class itself** rather than to individual objects (instances).

They are typically shared by all objects of that class.

```text
Instance member → belongs to each object
Static member   → belongs to the class
```

Static members can include **static variables (class variables)** and **static methods**.

---

## 1. Static Variable

A **static variable** is shared among all instances of a class.

For example, in Python:

```python
class Student:
    school = "ABC School"   # class/static variable

    def __init__(self, name):
        self.name = name     # instance variable


s1 = Student("Rahul")
s2 = Student("Aman")

print(s1.school)
print(s2.school)
```

Output:

```text
ABC School
ABC School
```

Both objects access the same class-level value.

Conceptually:

```text
Student class
     |
     └── school = "ABC School"
          ↑          ↑
         s1         s2
```

If `school` represents information common to all students, keeping one shared value is more appropriate than storing a separate copy for every object.

### Example of Shared Data

```python
class Student:
    school = "ABC School"

    def __init__(self, name, age):
        self.name = name
        self.age = age


s1 = Student("Rahul", 21)
s2 = Student("Aman", 22)

print(s1.name, s1.school)
print(s2.name, s2.school)
```

Output:

```text
Rahul ABC School
Aman ABC School
```

Here:

```text
school → shared by all students
name   → different for each student
age    → different for each student
```

---

## 2. Static Method

A **static method** belongs to the class and does not require an instance (`self`) to operate.

In Python, it can be created using `@staticmethod`:

```python
class MathUtils:

    @staticmethod
    def add(a, b):
        return a + b


result = MathUtils.add(10, 20)

print(result)
```

Output:

```text
30
```

Notice that we don't need:

```python
obj = MathUtils()
```

to call `add()`.

A static method is useful when a function is logically related to a class but doesn't need object-specific data.

### Example

```python
class Temperature:

    @staticmethod
    def celsius_to_fahrenheit(celsius):
        return (celsius * 9 / 5) + 32


temperature = Temperature.celsius_to_fahrenheit(25)

print(temperature)
```

Output:

```text
77.0
```

The method does not need information from a particular `Temperature` object, so it can be a static method.

## Static vs Instance Members

| Feature             | Static/Class Member                 | Instance Member         |
| ------------------- | ----------------------------------- | ----------------------- |
| Belongs to          | Class                               | Individual object       |
| Copies              | Generally shared                    | Each object has its own |
| Access              | Can often be accessed through class | Usually through object  |
| Python example      | Class variable / `@staticmethod`    | `self.name`             |
| Needs object state? | Not necessarily                     | Usually yes             |

### Example

```python
class Employee:
    company = "TechCorp"       # class/static member

    def __init__(self, name):
        self.name = name        # instance member

    @staticmethod
    def company_policy():
        return "Work from office 3 days a week"
```

Here:

```text
company
    ↓
Class-level data shared by employees

name
    ↓
Individual employee data

company_policy()
    ↓
Static method; doesn't need self
```

Usage:

```python
print(Employee.company)
print(Employee.company_policy())

employee = Employee("Rahul")

print(employee.name)
```

Output:

```text
TechCorp
Work from office 3 days a week
Rahul
```

## Important Language Difference

The exact meaning and syntax of static members varies by language.

For example, Java explicitly uses the `static` keyword:

```java
class Employee {
    static String company = "TechCorp";

    static void showCompany() {
        System.out.println(company);
    }
}
```

Usage:

```java
System.out.println(Employee.company);

Employee.showCompany();
```

In Java, `company` and `showCompany()` belong to the class rather than to individual `Employee` objects.

Python generally uses the terms **class variable** and **static method** rather than declaring a variable with a `static` keyword.

---

## When Should Static Members Be Used?

They are useful when the data or behavior is **common to the class** rather than specific to an individual object.

Examples include:

* Counters shared across instances
* Configuration/constants
* Utility functions
* Factory/helper methods
* Information common to all objects

### Example: Shared Counter

```python
class Student:
    total_students = 0

    def __init__(self, name):
        self.name = name
        Student.total_students += 1


s1 = Student("Rahul")
s2 = Student("Aman")
s3 = Student("Priya")

print(Student.total_students)
```

Output:

```text
3
```

Here, `total_students` is shared by all `Student` objects.

## Common Mistake

A static member should not be used simply because it is convenient.

If a value belongs to an individual object, it should normally be an **instance member**.

For example:

```text
Employee.company  → shared
employee.salary   → individual
employee.name     → individual
```

### Example

```python
class Employee:
    company = "TechCorp"

    def __init__(self, name, salary):
        self.name = name
        self.salary = salary
```

Here:

```text
company → same for employees
name    → different for each employee
salary  → different for each employee
```

So `company` is suitable as a class/static member, while `name` and `salary` should be instance members.

---

## Interview Takeaway

Static members belong to the **class rather than individual objects**.

Static variables can hold **class-level shared data**, while static methods provide behavior that doesn't depend on a particular object's state.

```text
Static member
     ↓
Belongs to class
     ↓
Usually shared

Instance member
     ↓
Belongs to object
     ↓
Usually unique for each object
```
