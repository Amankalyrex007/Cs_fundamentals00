Answer

The main difference is where the variable belongs and whether its value is shared.

Class variable → belongs to the class and is generally shared by all objects.
Instance variable → belongs to a particular object and can have a different value for each object.

Example in Python
class Student:
    school = "ABC School"      # class variable

    def __init__(self, name, age):
        self.name = name        # instance variable
        self.age = age          # instance variable


s1 = Student("Rahul", 21)
s2 = Student("Aman", 22)

Here:

school → class variable
name → instance variable
age → instance variable

Both objects generally access the same class variable:

print(s1.school)  # ABC School
print(s2.school)  # ABC School

But each object has its own instance variables:

print(s1.name)  # Rahul
print(s2.name)  # Aman

Conceptually:

Student class
│
└── school = "ABC School"     ← shared class variable
       ↑              ↑
      s1              s2

s1
├── name = "Rahul"             ← instance variable
└── age = 21

s2
├── name = "Aman"              ← instance variable
└── age = 22
Comparison
Feature	Class Variable	Instance Variable
Belongs to	Class	Individual object
Shared?	Generally shared among instances	No, each object has its own
Defined	Usually inside class, outside instance methods	Usually using self in Python
Access	ClassName.variable or through an object	Through an object
Example	Student.school	student.name
Use	Data common to objects	Object-specific data
Example with modification
class Employee:
    company = "TechCorp"

    def __init__(self, name):
        self.name = name


e1 = Employee("Rahul")
e2 = Employee("Aman")

Employee.company = "NewTech"

print(e1.company)  # NewTech
print(e2.company)  # NewTech

Because company is a class variable, changing the class-level value affects what both instances see unless an instance has its own attribute with that name.

In contrast:

e1.name = "Rohit"

print(e1.name)  # Rohit
print(e2.name)  # Aman

Changing e1.name does not change e2.name, because name is an instance variable.

Important Python nuance

If you assign an attribute through an instance:

e1.company = "ABC"

Python creates an instance attribute named company for e1, which can shadow the class variable:

print(e1.company)  # ABC
print(e2.company)  # NewTech

So class and instance attributes with the same name can coexist.

Interview takeaway

Class variables represent data shared at the class level, while instance variables represent data specific to individual objects. In Python, class variables are typically defined directly inside the class, while instance variables are usually created through self.
