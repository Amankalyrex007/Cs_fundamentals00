1.What is an operating system?
Definition

An Operating System (OS) is system software that acts as an interface between applications/users and computer hardware.

It manages hardware resources such as the CPU, memory, storage, and I/O devices, while providing services that applications use to run.

Examples:

Windows
Linux
macOS
Android
iOS
Why is an OS needed?

Without an OS, every application would have to directly manage hardware.

For example, instead of an application directly controlling a disk, it can simply request:

Application
     ↓
Operating System
     ↓
Disk / CPU / Memory / Devices

The OS handles the low-level details and provides a consistent interface to applications.

Major responsibilities of an OS
Responsibility	What it does
Process management	Creates, schedules, and terminates processes
Memory management	Allocates and manages RAM
File management	Organizes and manages files/directories
Device management	Controls I/O devices through drivers
CPU scheduling	Decides which process gets CPU time
Security & protection	Controls access to system resources
Networking	Provides network communication facilities
User interface	Provides CLI or GUI for interaction
Simple example

Suppose you open a browser.

The OS may:

Load the browser program from storage into memory.
Create a process for it.
Allocate memory.
Schedule its execution on the CPU.
Provide access to the keyboard, display, network, and files.
Protect the browser's memory from unrelated processes.
Kernel vs Operating System

The kernel is the core component of an operating system.

It directly manages critical resources such as:

CPU
Memory
Devices
Processes
System calls

The OS includes the kernel plus other system software and utilities that provide the complete operating environment.

Interview takeaway

An operating system is system software that manages computer hardware and provides services and abstractions that allow applications to execute safely and efficiently.
