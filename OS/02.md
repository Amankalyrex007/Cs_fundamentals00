2.What is a process?
Definition

A process is a program that is currently executing.

A program is a passive set of instructions stored on disk, while a process is the active execution of those instructions, along with the resources and state needed to run them.

Example

Suppose you have a Python program:

print("Hello")

The .py file stored on your computer is a program.

When you execute it:

Python Program
      ↓
Operating System
      ↓
Running Process

The OS creates a process and provides it with resources such as CPU time and memory.

What does a process contain?

A process typically has:

Program code (text section) — instructions being executed
Data — global/static data
Heap — dynamically allocated memory
Stack — function calls, local variables, etc.
Program counter — address of the next instruction to execute
CPU registers
Process state
Open files/resources

The OS keeps information about a process in a data structure commonly called a Process Control Block (PCB).

Common states are:

New — process is being created
Ready — waiting for CPU
Running — currently executing
Waiting/Blocked — waiting for an event such as I/O
Terminated — execution has finished
Process vs Program
Program	Process
Passive	Active
Stored instructions	Instructions currently executing
Usually stored on disk	Uses memory and CPU resources
Doesn't have execution state	Has execution state
One program can create multiple processes	Each process has its own execution context

For example, opening two instances of an application can result in multiple processes, depending on how that application and OS manage them.

Process vs Thread

A process is a resource and protection boundary, while a thread is an execution unit within a process.

Process
├── Code
├── Data
├── Heap
├── Resources
├── Thread 1
├── Thread 2
└── Thread 3

Multiple threads within the same process generally share its memory and resources, while separate processes normally have isolated address spaces.

Interview takeaway

A process is a program in execution, together with its execution state, memory, and allocated resources. The OS manages processes by creating, scheduling, suspending, and terminating them.
