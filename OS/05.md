5.What are the advantages of multithreading?
Multithreading allows a process to execute multiple threads concurrently. Its main advantage is that it can improve responsiveness, resource utilization, and throughput, depending on the workload and runtime.

1. Better responsiveness

A program can keep handling user interactions while another thread performs a long-running task.

Example:

Main Thread      → handles UI
Worker Thread    → processes a large file
Network Thread   → handles network requests

The UI doesn't necessarily have to wait for the file processing to finish.

2. Better CPU utilization

On a multi-core CPU, independent threads can execute in parallel on different cores.

CPU Core 1 → Thread 1
CPU Core 2 → Thread 2
CPU Core 3 → Thread 3
CPU Core 4 → Thread 4

This can improve performance for workloads that can actually be parallelized.

Important: multithreading and parallelism are not the same thing. Threads can be concurrent even on a single CPU core through scheduling.

3. Efficient handling of I/O-bound tasks

Threads can be useful when a program frequently waits for:

Network responses
Disk I/O
Database queries
File operations

While one thread is waiting, another thread may perform useful work.

Thread 1 → waiting for database
Thread 2 → processing another request
Thread 3 → handling network I/O
4. Lower overhead than processes

Threads within the same process share resources such as memory and code.

Therefore, creating and switching between threads is generally lighter than creating and managing separate processes, although the exact cost depends on the OS and runtime.

5. Easy communication through shared memory

Threads in the same process can access shared data structures.

Thread 1 ──┐
           ├── Shared Memory
Thread 2 ──┤
           └── Shared Data

This can make communication more efficient than communication between isolated processes.

However, shared memory also introduces risks such as:

Race conditions
Deadlocks
Data inconsistency

So synchronization may be necessary.

6. Higher throughput

For workloads that can be safely executed concurrently, multiple threads can allow a system to process more work over a given period.

For example, a web server can have multiple workers handling independent requests concurrently.

Summary
Advantage	Benefit
Responsiveness	Long tasks don't necessarily block other work
CPU utilization	Multiple cores can execute independent threads
I/O efficiency	Other threads can work while one waits
Lower overhead	Generally lighter than separate processes
Shared memory	Convenient communication between threads
Higher throughput	Multiple tasks can progress concurrently
Interview takeaway

The main advantages of multithreading are improved responsiveness, better CPU utilization, efficient handling of I/O-bound workloads, lower overhead than processes, shared-memory communication, and potentially higher throughput.

Important caveat: Multithreading does not automatically make a program faster. Synchronization overhead, contention, context switching, and workload characteristics can sometimes reduce or eliminate the benefit.
