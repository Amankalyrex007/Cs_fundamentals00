6.What is a process control block?
Definition

A Process Control Block (PCB) is a data structure maintained by the operating system to store important information about a process.

The OS uses the PCB to manage, schedule, suspend, resume, and track a process.

You can think of it as the process's record maintained by the OS.

What does a PCB contain?

A PCB typically contains information such as:

Information	Purpose
Process ID (PID)	Uniquely identifies the process
Process state	Ready, running, waiting, terminated, etc.
Program counter	Address of the next instruction
CPU registers	Saved CPU state of the process
CPU scheduling information	Priority, scheduling-related data, etc.
Memory-management information	Information about the process's address space/page tables
Accounting information	CPU usage, process statistics, etc.
I/O status	Open files and allocated I/O resources

The exact fields vary between operating systems.

Why is the PCB important?

Suppose the CPU is currently executing Process A:

CPU → Process A

The OS decides to switch to Process B.

It needs to save Process A's execution information so it can continue later.

Process A
    ↓
Save CPU state
    ↓
PCB of Process A
    ↓
Load state of Process B
    ↓
CPU → Process B

When Process A runs again, the OS restores its saved state from the PCB.

This is an important part of context switching.

PCB and context switching

Consider:

        CPU
         |
    Process A
         |
   Context Switch
         |
    Process B

During the switch, the OS roughly:

Saves Process A's current execution state in its PCB.
Updates Process A's state.
Selects Process B.
Loads Process B's saved state from its PCB.
Resumes Process B.

This allows multiple processes to share the CPU.

Simple analogy

Think of the PCB as a file maintained by the OS for each process.

It records:

"Who is this process, what state is it in, where did it stop, what CPU state did it have, what memory does it use, and what resources does it have?"

Interview takeaway

A Process Control Block is an OS-maintained data structure containing the information required to manage and execute a process, including its PID, state, program counter, CPU registers, scheduling information, memory information, and I/O resources. It is especially important during context switching.
