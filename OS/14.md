14.What is aging?
Definition

Aging is a technique used in CPU scheduling to gradually increase the priority of a process that has been waiting for a long time.

Its main purpose is to prevent starvation.

Example

Suppose lower numerical values mean higher priority:

P1 → Priority 10 → waiting
P2 → Priority 2  → running
P3 → Priority 3  → running

If higher-priority processes keep arriving, P1 might never get CPU time.

With aging, the OS gradually improves P1's priority:

Waiting time      Priority

0 ms                 10
10 ms                 9
20 ms                 8
30 ms                 7
...

Eventually, P1 becomes important enough to be scheduled.

P1 → gets CPU
Why is aging needed?

Without aging:

High priority → High priority → High priority → ...
                                      ↓
                              Low-priority process
                                      ↓
                                  Starvation

With aging:

Long waiting time
       ↓
Priority gradually increases
       ↓
Process eventually gets CPU
       ↓
Starvation reduced
Aging vs starvation

They are closely related:

Starvation = the problem where a process waits indefinitely.
Aging = a technique used to reduce/prevent that problem by increasing the priority of waiting processes.
Interview takeaway

Aging is a CPU scheduling technique in which the priority of a waiting process is gradually increased over time, ensuring that low-priority processes eventually get CPU time and reducing starvation.
