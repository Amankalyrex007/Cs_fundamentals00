18.What is a mutex?

A mutex (mutual exclusion) is a synchronization mechanism used to ensure that only one thread can access a shared resource or critical section at a time.

It helps prevent race conditions when multiple threads modify shared data.

How does a mutex work?

A mutex generally has two states:

Locked → another thread cannot enter the protected critical section.
Unlocked → a thread can acquire the mutex and enter.

Typical flow:

Thread 1 → acquire mutex → critical section → release mutex
Thread 2 → wait ───────────────────────────→ acquire mutex
Example
lock.acquire()

try:
    # Critical section
    counter += 1
finally:
    lock.release()

If Thread 1 holds the lock, Thread 2 must wait until Thread 1 releases it.

In Python, the same idea can be written more safely with a context manager:

with lock:
    counter += 1
Why is a mutex needed?

Consider two threads:

Thread 1: read counter = 10
Thread 2: read counter = 10
Thread 1: write 11
Thread 2: write 11

The expected result after two increments is 12, but the actual result can be 11.

A mutex ensures the operations happen safely:

Thread 1: lock → read 10 → write 11 → unlock
Thread 2: lock → read 11 → write 12 → unlock
Mutex vs semaphore
Mutex	Semaphore
Usually provides exclusive ownership	Controls access using a counter
Typically one thread owns the lock	Can allow multiple concurrent users
Commonly protects a critical section	Commonly limits access to a pool/resource
Conceptually: 1 at a time	Conceptually: N at a time
Important drawback

Improper mutex usage can cause deadlock. For example, Thread 1 holds Mutex A and waits for Mutex B, while Thread 2 holds Mutex B and waits for Mutex A.

So locks should generally be held for the shortest necessary duration and acquired in a consistent order when multiple locks are involved.

Interview takeaway

A mutex is a mutual-exclusion lock that allows only one thread at a time to access a protected critical section, helping prevent race conditions.
