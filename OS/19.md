19.What is a semaphore?
A semaphore is a synchronization mechanism that uses a counter to control access to a shared resource or a limited number of resources.

Unlike a mutex, which generally allows only one thread to enter a critical section, a semaphore can allow multiple threads to access a resource simultaneously, up to a specified limit.

How does a semaphore work?

A semaphore maintains a counter representing the number of available permits.

Two common operations are:

Wait / Acquire → decreases the counter. If no permit is available, the thread waits.
Signal / Release → increases the counter and may wake a waiting thread.

For example, with a semaphore initialized to 3:

Semaphore = 3

Thread 1 → acquire → 2
Thread 2 → acquire → 1
Thread 3 → acquire → 0
Thread 4 → waits

When one thread releases its permit:

Thread 1 → release → 1
Thread 4 → can now acquire
Example

Suppose a server has 3 database connections available.

Instead of allowing 20 threads to use the database simultaneously, a semaphore can limit access to 3:

import threading

semaphore = threading.Semaphore(3)

with semaphore:
    # Access limited resource
    use_database()

At most three threads can be inside the protected resource section at the same time.

Semaphore vs Mutex
Mutex	Semaphore
Usually allows one thread at a time	Can allow multiple threads
Represents exclusive ownership	Represents available permits/resources
Commonly protects a critical section	Commonly limits concurrent access
Usually binary: locked/unlocked	Usually has a counter: 0, 1, 2, ...
Types of semaphores

1. Binary semaphore

Counter is effectively 0 or 1.

0 → unavailable
1 → available

It can resemble a mutex, although mutexes and binary semaphores have different ownership semantics depending on the implementation.

2. Counting semaphore

Counter can be greater than 1.

Example:

Semaphore(5)

allows up to five concurrent accesses.

Interview takeaway

A semaphore is a counter-based synchronization mechanism used to control how many threads or processes can access a resource concurrently. A mutex generally provides exclusive access, while a counting semaphore can allow a limited number of concurrent accesses.
