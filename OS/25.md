25.What is virtual memory?
Virtual memory is a memory-management technique that allows a system to use part of the secondary storage (SSD/HDD) as an extension of RAM.

It gives each process the illusion that it has a large, continuous memory space, even when physical RAM is limited.

How it works

The OS divides memory into fixed-size pages:

A process generates a virtual address.
The OS/MMU maps the virtual address to a physical address in RAM using page tables.
If the required page is not currently in RAM, a page fault occurs.
The OS loads that page from disk into RAM, possibly evicting another page.
Execution continues.
Process
   ↓
Virtual Address
   ↓
Page Table / MMU
   ↓
Physical RAM
   ↓
If page absent → Page Fault → SSD/HDD
Example

Suppose a computer has 4 GB RAM, but running processes require more memory.

Virtual memory allows processes to address more memory than the currently available physical RAM by keeping less frequently used pages on disk and bringing them into RAM when needed.

Why is virtual memory used?
Allows programs larger than available RAM to run.
Provides process isolation—one process normally cannot directly access another's memory.
Makes memory allocation easier by providing each process its own virtual address space.
Enables techniques such as paging and memory-mapped files.
Important drawback

Disk/SSD is much slower than RAM. If the system constantly moves pages between RAM and disk, thrashing can occur, causing severe performance degradation.

Interview takeaway

Virtual memory abstracts physical memory by giving processes a virtual address space and using mechanisms such as paging to map virtual addresses to RAM, with inactive pages potentially stored on secondary storage.
