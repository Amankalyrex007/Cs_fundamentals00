26.What is paging?
Paging is a memory-management technique in which virtual memory is divided into fixed-size blocks called pages, while physical memory (RAM) is divided into fixed-size blocks called frames.

The OS maps virtual pages to physical frames using a page table.

How paging works
Virtual Memory                 Physical Memory (RAM)

Page 0 ────────────────→ Frame 3
Page 1 ────────────────→ Frame 7
Page 2 ────────────────→ Frame 1
Page 3 ────────────────→ Frame 5

A virtual address is typically divided into:

Virtual Address
┌──────────────┬──────────────┐
│ Page Number  │ Page Offset  │
└──────────────┴──────────────┘
Page number → used to find the corresponding frame in the page table.
Page offset → identifies the exact location within that frame.
Example

Suppose:

Page size = 4 KB
A process needs 16 KB of virtual memory.

It is divided into:

16 KB / 4 KB = 4 pages

Those four pages don't need to occupy four consecutive locations in RAM. They can be placed in any available frames.

What happens if a page isn't in RAM?

If the required page is not currently in physical memory, a page fault occurs.

The OS then:

Finds the required page on secondary storage.
Finds a free frame, or chooses a page to evict.
Loads the required page into RAM.
Updates the page table.
Restarts/continues the interrupted instruction.
Advantages
Avoids the need for contiguous physical memory.
Supports virtual memory efficiently.
Reduces external fragmentation.
Allows processes to use pages independently of their physical location.
Provides memory isolation between processes.
Disadvantages
Page tables require additional memory.
Address translation adds overhead, usually reduced using a TLB (Translation Lookaside Buffer).
Page faults are expensive because accessing storage is much slower than accessing RAM.
Paging can contribute to thrashing if too many page faults occur.
Paging vs virtual memory

A useful interview distinction:

Virtual memory is the overall memory abstraction; paging is one of the main techniques used to implement it.

Interview takeaway:

Paging divides virtual memory into fixed-size pages and physical memory into equal-size frames, then uses a page table to map pages to frames.
