29.What is page replacement?
Page replacement is the process of selecting a page currently in physical memory (RAM) to remove when a page fault occurs and there is no free frame available for the required page.

The OS replaces an existing page with the required page.

How it works
Page Fault
    ↓
Is there a free frame?
 ├── Yes → Load required page
 └── No
      ↓
Select a victim page
      ↓
If victim is modified → Write it back to disk
      ↓
Load required page into that frame
      ↓
Update page table
      ↓
Resume execution
Example

Suppose RAM has 3 frames:

Frame 1 → Page 2
Frame 2 → Page 5
Frame 3 → Page 7

A process requests Page 3, but all frames are occupied.

The OS must choose one existing page—for example, Page 5—to remove:

Before:
Frame 1 → Page 2
Frame 2 → Page 5  ← victim
Frame 3 → Page 7

After:
Frame 1 → Page 2
Frame 2 → Page 3  ← required page
Frame 3 → Page 7

The page chosen for removal is called the victim page.

Common page replacement algorithms
Algorithm	Basic idea
FIFO	Replace the page that has been in memory the longest
Optimal	Replace the page that will not be used for the longest time in the future
LRU	Replace the page that has not been used for the longest time
Clock / Second Chance	Gives recently referenced pages another chance before replacement

Optimal is mainly used as a theoretical benchmark because the OS cannot know the future exactly.

Important goal

A good page replacement algorithm tries to minimize page faults, because handling page faults is expensive.

Page replacement vs page fault
Page fault: Required page is not currently in RAM.
Page replacement: If RAM has no free frame, the OS decides which existing page to remove so the required page can be loaded.

Interview takeaway:

Page replacement is the mechanism used by the OS to select and remove a page from RAM when a page fault occurs and no free frame is available.
