32.What is fragmentation?
Fragmentation is a memory-management problem where available memory is divided into smaller pieces, causing memory to be used inefficiently.

There are two main types:

1. Internal Fragmentation

Internal fragmentation occurs when allocated memory is slightly larger than what a process actually needs, leaving unused space inside the allocated block.

Example:

Frame size = 4 KB
Process needs = 3 KB

┌────────────────────┐
│ Used: 3 KB         │
│ Unused: 1 KB       │ ← Internal fragmentation
└────────────────────┘

This is commonly associated with fixed-size allocation, such as paging.

2. External Fragmentation

External fragmentation occurs when free memory exists, but it is split into many small, non-contiguous blocks.

Example:

┌──────┬──────┬──────┬──────┬──────┐
│ Used │ Free │ Used │ Free │ Used │
└──────┴──────┴──────┴──────┴──────┘
         ↑            ↑
      Free blocks are separated

There may be enough total free memory, but not one sufficiently large contiguous block for a new allocation.

This is commonly associated with variable-sized contiguous memory allocation and segmentation.

Internal vs External Fragmentation
Aspect	Internal	External
Wasted space	Inside allocated block	Between allocated blocks
Typical cause	Fixed-size allocation	Variable-size allocation
Example	Paging	Segmentation
Main issue	Allocated space isn't fully used	Free space isn't contiguous
How can fragmentation be reduced?
Internal fragmentation: choose appropriate allocation/page sizes.
External fragmentation: techniques such as compaction can combine scattered free blocks, though compaction has overhead.
Paging avoids external fragmentation of physical allocation because pages can occupy non-contiguous frames, but it can still have internal fragmentation.
Interview Takeaway

Internal fragmentation wastes space inside allocated blocks, while external fragmentation occurs when free memory is scattered into small, non-contiguous blocks.
